# Portfolio ✦

Mi portfolio personal. Hecho desde cero con HTML, CSS y JS.

---

## ¿Qué es esto?

Un sitio WEB que construí para mostrar quién soy y en qué estoy trabajando.

Actualmente estoy cursando una Tecnicatura en Desarrollo de Software en la UCU, así que esto también es parte del proceso de aprender haciendo.

---

## Stack

- **HTML / CSS / JS**
- **Lenis** — smooth scroll
- **Google Fonts** — Syne + DM Mono

---

## Features

- Intro animado estilo terminal
- Parallax en hero y secciones
- Red de partículas interactiva con canvas
- Grid cells que vuelan desde fuera del viewport al hacer scroll
- Cursor personalizado con estados
- Efecto scramble en el nombre al hover
- Modo claro / oscuro
- Responsive + menú hamburguesa para mobile
- Ticker horizontal animado
- Tilt 3D en cards de proyectos
- Glitch ocasional en el logo
